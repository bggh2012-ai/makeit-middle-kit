메킷 키트를
내 것으로 고쳐 쓰기

키트를 내 깃허브로 복사해서, 내가 원하는 대로 고쳐 씁니다.
원래 키트는 그대로 둡니다. 둘 다 계속 쓸 수 있어요.

먼저 챙길 것

  • 1주차부터 쓰던 작업 폴더 — 설치·키 설정이 끝난 폴더 (원본 키트)
  • 크롬 + 코덱스 크롬 확장 — 네이버 글쓰기 때 쓰던 그대로
  • 깃허브 계정 — 없으면 github.com 에서 무료로 직접 가입하세요 (코덱스가 대신 가입하지 않아요)
  • chatgpt.com/codex — 키트를 고칠 때 쓰는 코덱스 웹 (ChatGPT Plus 이상)
고치는 건 온라인에서만 합니다내 컴퓨터에서는 키트 코드를 내려받거나 고치지 않습니다. 코드는 내 깃허브에만 있고, 고치는 건 코덱스 웹(chatgpt.com/codex)에서 합니다. 내 컴퓨터의 코덱스 앱은 지금처럼 쓰기만 합니다.
1

원래 폴더에서 이 한 줄

ChatGPT 앱 → Codex → 새 채팅 → 작업 폴더로 1주차부터 쓰던 폴더를 고르고, 아래 문장을 붙여넣으세요.

내 커스텀 키트 만들어줘

크롬이 저절로 움직여요코덱스가 크롬에서 깃허브의 '복사(포크)' 화면을 열고 초록색 Create fork 버튼을 누릅니다. 그동안 마우스·키보드는 잠깐 쉬세요.
2

깃허브 로그인 · Create fork

깃허브 로그인이 안 돼 있으면 코덱스가 “크롬에서 깃허브에 로그인해 주세요” 라고 합니다. 크롬에 열린 깃허브 화면에서 직접 로그인하고 됐어요 라고 답하세요.

“Create fork 버튼을 눌러 주세요” 라고 하면코덱스가 버튼을 못 누른 경우입니다. 알려 준 주소의 화면에서 초록색 Create fork 를 직접 누르고 만들었어요 라고 답하세요. 같은 이름 저장소가 이미 있다고 하면 Repository name 칸을 makeit-middle-kit-my 처럼 바꾼 뒤 누르세요.
“예전에 만들어 둔 복사본이 있어요” 라고 하면예전에 직접 복사(포크)해 둔 저장소가 옛 판입니다. 그 화면에서 Sync fork → Update branch 를 누르고 됐어요 라고 답하세요.
3

새 폴더 ‘메킷 커스텀 키트’ 로 쓰기

다 되면 원래 폴더 옆에 메킷 커스텀 키트 폴더가 생깁니다. 키 설정(수강 코드·OpenAI 키·워드프레스 연결)은 그대로 옮겨 놓아요.

원본원래 작업 폴더지금까지처럼 원본 키트
·
내 것메킷 커스텀 키트내 깃허브 저장소로 도는 키트

내 커스텀 키트를 쓰려면 코덱스에서 새 채팅 → 작업 폴더로 메킷 커스텀 키트 를 고르고 평소처럼 말하세요 (승인글 자동화 시작해, 네이버 글 써줘 …).

4

고치기 — 코덱스 웹에서

컴퓨터 브라우저로 chatgpt.com/codex 에 들어갑니다.

  1. 처음 한 번: 깃허브 연결(Connect GitHub) → 내 깃허브 계정 허용 → 저장소 내아이디/makeit-middle-kit 를 고릅니다.
  2. 저장소를 고른 채로 바꾸고 싶은 것 한 가지를 적습니다.
  3. 코덱스가 고친 내용을 보여 주면 Create PR(PR 만들기)를 누릅니다.

네이버 글 마무리 문단 끝에 "이웃 추가하시면 새 글을 바로 받아 보실 수 있어요" 한 문장을 늘 넣어줘. 다른 건 바꾸지 마.

무엇을 바꿀지 모르겠다면이 키트에서 내가 바꿀 만한 것 세 가지를 쉽게 제안해줘. 아직 고치지 마. 라고 먼저 물어보세요.
키·비밀번호는 절대 적지 마세요내 저장소는 공개입니다. OpenAI 키·워드프레스 비밀번호는 지금처럼 내 컴퓨터의 키설정.txt 로만 넣습니다.
5

깃허브에서 Merge

PR 화면(깃허브)에서 Merge pull request → Confirm merge 를 누르면 끝입니다. 메킷 커스텀 키트 폴더에서 다음 실행부터 바로 바뀐 대로 돕니다 (켜 둔 채팅도 2분 안에 바뀝니다).

마음에 안 들면 되돌리기깃허브의 그 PR 화면에서 Revert → 새로 생긴 PR 을 Merge 하면 원래대로 돌아갑니다. 코덱스 웹에 방금 바꾼 걸 되돌려줘 라고 해도 됩니다.
6

원본 키트의 새 내용 받기

원본 키트가 좋아지면 원래 폴더에는 저절로 들어옵니다. 내 커스텀 키트에도 넣고 싶으면 깃허브의 내 저장소 화면에서 Sync fork → Update branch 를 누르세요.

‘Discard’ 버튼은 누르지 마세요충돌(conflict) 이야기가 나오면 아무것도 누르지 말고 닫으세요. ‘Discard’ 는 내가 고친 내용을 지웁니다. 원본의 새 기능은 원래 폴더에서 언제든 쓸 수 있어요.

막혔을 때

내 컴퓨터 코덱스에게 고쳐 달라고 했어요“키트 고치기는 온라인에서 해요” 라고 답합니다. 4번대로 코덱스 웹에서 하세요.
고친 뒤 오류가 나요원래 폴더에서 같은 일이 되면 내가 고친 부분 때문입니다. 5번의 Revert 로 되돌리세요.
‘내 커스텀 키트 저장소를 읽지 못했어요’깃허브에서 내 저장소 이름을 바꿨거나 지웠는지 확인하세요. 다시 만들려면 원래 폴더에서 1번부터.
코덱스 웹에 내 저장소가 안 보여요깃허브 연결 화면에서 내 저장소(makeit-middle-kit) 접근을 허용했는지 확인하세요.
강사용 — 어떻게 도는지 · 주의할 점 · 검증 범위

어떻게 도는지. ‘내 커스텀 키트 만들어줘’ → 코덱스 크롬 확장으로 github.com/makeit-edu/makeit-middle-kit/fork 를 열어 Create fork 를 누름(못 누르면 수강생이 누름) → 원래 폴더 옆에 ‘메킷 커스텀 키트’ 폴더를 만들고 대본(AGENTS.md)의 준비 코드 저장소 줄을 수강생 저장소로 바꿔 깔고, 애드센스 승인글/00_설정/키트저장소.txt 표시를 남김 → 설정.json 복사. 그 폴더는 실행할 때마다 수강생 저장소 main 의 최신 커밋을 받아 씁니다(원본은 목록.json 고정 커밋). 전역 ~/.codex/AGENTS.md(원본 대본)는 건드리지 않습니다.

주의. ① 포크는 공개 저장소라 누구나 코드를 볼 수 있고, 원본 저장소의 Forks 목록에 서로 보입니다(키는 깃허브에 없음). ② 원본 목록.json 의 정지 스위치로 포크는 멈출 수 없습니다 — 각자 사본입니다. ③ 원본 업데이트는 Sync fork 를 눌러야 들어갑니다. ④ 수강생이 고친 코드로 난 오류는 원래 폴더에서 같은 일이 되는지로 가립니다. ⑤ 코덱스 웹이 저장소를 고칠 때 따르는 규칙은 저장소 맨 위 AGENTS.md ‘이 저장소를 고칠 때’ 에 있습니다.

검증 범위 (2026-10-17). 비공개 시험 저장소(makeit-edu/kit-custom-test)와 가짜 홈 폴더로 31개 항목 통과: 커스텀 설치·폴더 대본 저장소 줄·표시 파일·전역 대본 안 건드림·최신 main 커밋 사용·표시 파일 우선·원본 재설치 시 표시 삭제, 포크 만들기 흐름(가짜 크롬: 로그인 필요·옛 복사본·이름 겹침·버튼 꺼짐·화면 밖 버튼·새 폴더·설정 복사), 병합 후 켜 둔 채팅 129초 만에 새 코드. 아직 확인 전: 로그인된 진짜 깃허브에서 Create fork 누르기, 코덱스 웹 화면 이름(Connect GitHub·Create PR 은 바뀔 수 있음), Windows.
